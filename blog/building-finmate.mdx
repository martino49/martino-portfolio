## The Idea

FinMate started as a personal project. I needed a way to track my expenses, set budgets, and manage savings goals — but most finance apps were either too complex or too simple.

![FinMate Login Page — clean, branded authentication with navy/teal theme](/images/finmate/01-login.png)

I wanted to build something that could work for both individuals and teams, with proper role-based access control.

## Tech Stack

- **Frontend:** EJS templates with Bootstrap 5 and Chart.js
- **Backend:** Node.js + Express
- **Database:** MySQL with auto-schema creation
- **Auth:** JWT with HTTP-only cookies, role-based access control (5 roles)
- **Security:** Helmet, rate limiting, input sanitization, compression

## Key Features

### 1. Role-Based Access Control

The system has 5 roles: Super Admin, Admin, Team Leader, Team Member, and Individual User. Each role has a dedicated dashboard and permission-guarded routes.

![Individual User Dashboard — overview of daily expenses, budgets, savings progress, and recent transactions](/images/finmate/02-user-dashboard.png)

### 2. Expense Tracking

Users can log expenses with categories, dates, and amounts. The dashboard shows spending trends with interactive charts, and filters let you drill down by period and category.

![Expense Management — full CRUD with filters, summary stats, and category breakdown](/images/finmate/03-user-expenses.png)

### 3. Budget Management

Set monthly, weekly, or yearly budgets per category. The system tracks actual vs. planned spending and shows progress bars for each budget.

![Budget Management — create, edit, and track budgets with progress indicators](/images/finmate/04-user-budgets.png)

### 4. Savings Goals

Create savings goals with target amounts and deadlines. Track progress over time with visual indicators and make deposits toward each goal.

![Savings Goals — set targets, track deposits, and monitor progress](/images/finmate/05-user-savings.png)

### 5. Income Tracking

Record income by source and category. Filter by status (pending, confirmed) and time period to get a clear picture of cash flow.

![Income Tracking — log and manage income sources with status filters](/images/finmate/06-user-incomes.png)

### 6. Analytics Dashboard

Visual analytics with Chart.js for spending patterns, budget utilization, and category breakdowns. Helps users understand where their money goes.

## Challenges

The biggest challenge was implementing the auto-schema creation on deployment. When the app boots, it checks if the database schema exists and creates it if needed, including seeding default roles, permissions, and role-permission mappings.

Another significant challenge was designing the unified sidebar — a single EJS partial that adapts its navigation based on the user's role, with collapse persistence, mobile responsive overlay, and consistent logout styling across all views.

## Security

- **Helmet** — Sets secure HTTP headers
- **Rate limiting** — 100 requests/15min on API routes
- **Input sanitization** — Strips XSS vectors on mutation routes
- **JWT + HTTP-only cookies** — Tokens not accessible via JavaScript
- **bcryptjs** — Password hashing with salt rounds
- **SQL injection protection** — Parameterized queries throughout
- **Compression** — gzip response compression

## Results

- 5-role RBAC with proper permission guards
- 209 routes across all roles
- Real-time charts and visualizations
- Auto-schema creation on boot
- Unified responsive sidebar
- Security hardened (Helmet, rate limiting, sanitization)
